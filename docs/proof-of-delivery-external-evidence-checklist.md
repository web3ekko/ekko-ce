# Proof of Delivery: External Evidence Checklist

Attach these artifacts alongside:
`docs/proof-of-delivery-ekko-milestones-2-3-v0.3.pdf`

## Milestone 2

- Partner roster showing at least 5 Avalanche L1 enterprise partners
- Signed MoUs / partnership confirmations (or redacted attestations)
- Beta cohort confirmation list with partner names and onboarding dates

## Milestone 3

- iOS App Store submission proof (App Store Connect screenshots or export)
- Google Play submission proof (Play Console screenshots or export)
- Browser extension QA report and test summary
- Security testing report / vulnerability assessment summary
- Enterprise paid feature rollout evidence (billing/feature flags/release note)

- `m2-partner-roster.pdf`

- `m3-android-submission-proof.pdf`
